Broccoli Queue is a production-ready message queue library for Rust, designed as a type-safe alternative to Celery. It provides a unified async API over Redis, RabbitMQ, and SurrealDB backends — letting you publish, consume, and process jobs with full control over retries, scheduling, and concurrency.

## Why Broccoli Queue?

Broccoli Queue brings Celery-style distributed job processing to Rust without sacrificing type safety or performance. Every message is generically typed and serialized with Serde — no stringly-typed payloads.

## Get Started in Minutes

<Steps>
  <Step title="Add the dependency">
    Add `broccoli_queue` to your `Cargo.toml` with the broker feature you need:

    ```toml Cargo.toml
    [dependencies]
    broccoli_queue = { version = "0.4.6", features = ["redis"] }
    tokio = { version = "1", features = ["full"] }
    serde = { version = "1", features = ["derive"] }
    ```
  </Step>
  <Step title="Define your message type">
    Create a serializable struct representing your job payload:

    ```rust
    use serde::{Serialize, Deserialize};

    #[derive(Debug, Clone, Serialize, Deserialize)]
    struct EmailJob {
        to: String,
        subject: String,
    }
    ```
  </Step>
  <Step title="Publish a message">
    Build a queue and publish your first job:

    ```rust
    use broccoli_queue::queue::BroccoliQueue;

    let queue = BroccoliQueue::builder("redis://localhost:6379")
        .pool_connections(5)
        .build()
        .await?;

    queue.publish("emails", None, &EmailJob {
        to: "user@example.com".into(),
        subject: "Welcome!".into(),
    }, None).await?;
    ```
  </Step>
  <Step title="Consume and process">
    Subscribe to the queue and process messages with a typed handler:

    ```rust
    use broccoli_queue::brokers::broker::BrokerMessage;

    queue.process_messages(
        "emails",
        Some(4), // 4 concurrent workers
        None,
        |msg: BrokerMessage<EmailJob>| async move {
            println!("Sending email to: {}", msg.payload.to);
            Ok(())
        },
    ).await?;
    ```
  </Step>
</Steps>
